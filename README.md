📊 Myntra Sales Analytics Dashboard

A clean and interactive dashboard built using Power BI

📝 1. Overview

This project presents a fully interactive Myntra Sales Analytics Dashboard created using Power BI.
I combined multiple CSV files, cleaned the data, built relationships, and designed insights that help understand product performance, customer behavior, and sales trends.

📁 2. Dataset

The dataset contains multiple tables such as:

Orders Table

Products Table

Customers Table

Payments / Transactions Table

Each table was connected using proper relationships to form a clean data model.

🛠️ 3. Tools & Skills Used

Power BI (Data Cleaning, Modelling, DAX, Visualization)

Power Query Editor

Data Modelling (Star Schema)

Interactive Visualizations

Drill-Through & Tooltip Pages

Slicers & Filters

⚙️ 4. Steps Performed
🔹 Data Cleaning

Removed duplicates

Fixed formatting issues

Cleaned product names, categories, and prices

Handled missing / null values

🔹 Data Modelling

Created relationships between tables

Built a clean star schema

Joined tables using common keys

🔹 Dashboard Building

Added KPIs for Total Sales, Total Orders, Total Profit, Avg Rating

Designed charts for Category-wise Sales, Brand Sales, Payment Method Share, Top Products

Added interactive slicers

Added advanced tooltip pages to show extra information when hovering

📊 5. Key Insights

Top-selling categories and brands

Customer buying patterns

Revenue contribution by payment methods

High-performing and low-performing products

Rating trends across categories

Stock availability vs demand

🎯 6. Features

100% Interactive Dashboard

Real-time updates with slicers
→ Example: “When the Payment Method slicer is used, the entire dashboard updates instantly.”

Clean and professional UI

Drill-through analysis

Tooltip insights

Easy to understand and navigate

📎 7. Project Purpose

To analyze Myntra’s sales data and understand:

What sells the most

Who buys the most

Which payment methods are preferred

How stock, rating, and price impact sales

This dashboard supports data-driven decision making for e-commerce performance.

🚀 8. Conclusion

This project shows how interactive dashboards can help businesses understand their sales patterns quickly and make better decisions.
It also demonstrates my skills in Power BI, data cleaning, data modelling, and visualization.
